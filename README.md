# JavaScript Learning Journey 🚀

This repository contains a comprehensive collection of JavaScript exercises, examples, and notes organized by chapters. It serves as a structured way to learn JS from basics to advanced concepts.

## 📂 Project Structure

The project is organized into chapters, each focusing on a specific JavaScript topic:

- **Chapter 01: Basics** - Basic syntax, commands, and operators.
- **Chapter 02: JavaScript Concepts** - Variables, functions, and hoisting.
- **Chapter 03: Literals** - Data types, null, and undefined.
- **Chapter 04: Operators** - Arithmetic, logical, comparison, and nullish coalescing.
- **Chapter 05: Conditionals** - If/else statements and truthy/falsy values.
- **Chapter 06: Switch** - Implementation of switch cases.
- **Chapter 07: User Input** - Handling user input in JS.
- **Chapter 08: Loops** - For, while, and do-while loops, including pattern printing.
- **Chapter 09: Arrays** - Array manipulation and methods.
- **Chapter 20: JS OOPS** - Object-Oriented Programming in JS, including Inheritance.

## 🚀 How to Run

Since these are standalone JavaScript files, you can run them using Node.js.

### Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.

### Running a File
Navigate to the directory and run the file using the `node` command:

```bash
node Chapter_01_Basics/01_basics.js
```
